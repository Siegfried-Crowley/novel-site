# 📖 公益小说在线阅读站

公益免费、无需登录、公开浏览的轻量小说阅读站。管理端「一键上传 TXT」→ 自动解析成小说 → 前台像真小说站一样有封面、简介、分类、排行、阅读页。内置 TXT 硬折行自动排版、后台线程解析、管理端本机保护等能力。

## 快速开始

需要 **Node.js 22+**（没有就去 https://nodejs.org/ 装一个；依赖里的 better-sqlite3 要求 22 以上）。

### 方式一：双击启动（推荐）

直接双击项目里的 **`start.bat`**，会自动完成「安装依赖 + 启动服务」。

### 方式二：命令行一键启动（复制即用）

**CMD**（开始菜单搜 cmd 打开）：
```bat
cd /d "D:\idea databas\novel-site" && npm install && npm start
```

**PowerShell**：
```powershell
cd "D:\idea databas\novel-site"; npm install; npm start
```

**Git Bash**：
```bash
cd "/d/idea databas/novel-site" && npm install && npm start
```

> `npm install` 只在第一次（或依赖变动后）真正下载，之后运行是秒过的，所以每次都带上它最省事。

看到 `📖 小说阅读站已启动: http://localhost:3000` 就成功了：

- **前台浏览**：浏览器打开 http://localhost:3000
- **管理后台**：打开 http://localhost:3000/admin （从这里上传 TXT）

**停止服务**：在运行 `npm start` 的那个终端按 `Ctrl + C`（会优雅关闭：处理完进行中的请求并把数据库落盘后再退出）。

**启动报错「端口被占用」**：说明已经有一个实例在跑（或上次没关干净）。要么直接用现成的，要么先结束占用进程：
```bat
netstat -ano | findstr :3000
taskkill /F /PID 你的PID
```

**想启动就带管理口令**（公网部署必设）：
```bat
set ADMIN_PASSWORD=你的口令 && cd /d "D:\idea databas\novel-site" && npm start
```

> 数据全部在本地，备份 = 复制 `data/` 文件夹。

## 功能一览

**管理端**
- 一键上传：拖拽 TXT（支持多本批量），自动识别编码（UTF-8 / GBK / GB18030）、书名、作者，自动切分章节，同名书籍覆盖更新；上传后自动跳转编辑页。解析在工作线程进行，**大文件上传/切分时前台读者完全不受影响**
- **自动排版**：一键检测「固定宽度硬折行」排版（每行断在句子中间），先预览重排前后对比，确认后整书重排（只重新分段、不增删文字）；编辑单章时也可「重排本段」
- 改书籍信息（含重新传封面）、改/删/增章节、调整章节顺序、用不同正则重新切分（正则防误写：语法校验 + 长度上限 + 超时兜底）
- 评论管理：查看 / 按书名筛选 / 删除读者评论

**前台**
- 首页：轮播推荐 + 分类导航 + 热门搜索词 + 最近在读（进度存本浏览器）+ 最新更新 + 热门推荐
- 列表页：分类 / 搜索 / 排序（最新更新、最新入库、阅读量、收藏、字数）/ 状态（连载·完结）/ 字数区间筛选 + 分页
- 详情页：大封面、简介、最新章节更新时间、章节目录（每章字数、展开收起）、评分（1~5 星，匿名去重）、书评区（防刷限流）、同类推荐、收藏（"共 X 人收藏"）
- 阅读页：4 种阅读主题（羊皮纸 / 护眼绿 / 夜间…）、字号小中大、字体、行距、沉浸模式（自动隐藏顶栏）、读完自动翻章、键盘 ← → 翻页、目录抽屉、进度记忆
- 我的收藏：本浏览器收藏的书一键续读（点击直接跳到上次读到的章节）
- 排行：阅读榜 / 收藏榜 / 更新榜

**机制**
- 自动封面：未传封面时按书名自动生成渐变 SVG 封面（带一日缓存）
- 管理端安全：设口令后登录有恒时比较 + 失败限流（同 IP 每分钟 5 次），会话 7 天过期；未设口令时管理端**仅限本机访问**
- 阅读量防刷：同一 IP 30 秒内进同一章只 +1（`X-Forwarded-For` 只信任本机反代，伪造无效）
- 收藏 / 评分去重：匿名 cookie，同一浏览器对同一本书只算一次
- 评论防刷：同一 IP + 浏览器 30 秒内只能发一条
- 上传封面目录禁止脚本执行（CSP sandbox），文本响应全站 gzip 压缩

## 配置

编辑 `config.js` 或用环境变量：

| 配置 | 环境变量 | 默认 | 说明 |
|------|---------|------|------|
| 管理口令 | `ADMIN_PASSWORD` | 空 | **留空 = 管理端仅限本机（127.0.0.1）访问**；公网部署必须设置 |
| 端口 | `PORT` | 3000 | 监听端口 |
| 反代层数 | `TRUST_PROXY` | `loopback` | 只信任本机反向代理（Nginx 与 Node 同机的常见部署）。反代不在本机时设为 `1` 或 `true`；直接暴露时保持默认即可 |

## 主要接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/books?cat=&q=&sort=&status=&minWords=&page=` | 书籍列表（分类 / 搜索 / 排序 / 状态 / 字数 / 分页） |
| GET | `/api/books?ids=1,2,3` | 批量按 id 取书（我的收藏 / 最近在读） |
| GET | `/api/search/hot` | 热门搜索词（近 30 天 Top10，日志自动清理 90 天前记录） |
| GET | `/api/books/:id` | 详情（目录、每章字数、最新章节时间、评分、收藏状态、同类推荐） |
| GET | `/api/chapters/:id` | 章节正文（阅读量 +1，带防刷） |
| POST | `/api/books/:id/favorite` | 收藏 / 取消（匿名 cookie 去重；可带 `{action:"add"\|"remove"}` 明确意图） |
| POST | `/api/books/:id/rate` | 评分 1~5 星（匿名去重，可改分） |
| GET / POST | `/api/books/:id/comments` | 书评列表 / 发表（30 秒防刷） |
| GET | `/api/rank?type=views\|favorites\|updated` | 排行榜 |
| POST | `/api/admin/upload` | 上传 TXT（multipart，`files` 字段，仅 `.txt`；结果附带排版质量报告 `format`） |
| POST | `/api/admin/books/:id` | 更新书籍信息 |
| PUT / DELETE | `/api/admin/chapters/:id` | 编辑 / 删除章节 |
| POST | `/api/admin/books/:id/reparse` | 重新切分（可带自定义正则） |
| POST | `/api/admin/books/:id/format` | 自动排版：默认 dry-run 返回检测汇总 + 前 3 章预览；`{apply:true}` 事务内重排全书 |
| POST | `/api/admin/chapters/:id/reflow` | 单章重排预览（不写库，截断超长章节） |
| DELETE | `/api/admin/books/:id` | 删除书籍 |
| GET / DELETE | `/api/admin/comments[/:id]` | 评论列表（可带 `?novel_id=` 筛选）/ 删除 |

## 部署上线

先选一条路线：

| 路线 | 服务器 | 备案 | 上线速度 | 适合 |
|------|--------|------|---------|------|
| **A. 香港/海外** | 香港轻量服务器 | 免备案 | 当天 | 试水、小圈子、不想等备案 |
| **B. 国内** | 国内云服务器 | 需 1~3 周 | 备案通过后 | 正式运营（微信 / 百度可用）|

### 路线 A：香港免备案（推荐先试）

1. **买服务器**：阿里云 / 腾讯云「轻量应用服务器」，地域选**香港**，配置 2 核 2G，系统 Ubuntu 22.04
2. **买域名 + 解析**：任意服务商买域名，加一条 **A 记录**指向服务器 IP（免备案，解析生效即可访问）
3. **连服务器装环境**：SSH 登录后安装 **Node.js 22+**
4. **传代码**：`git clone` 你的仓库，或压缩上传解压；然后 `npm install`
5. **设管理口令**：启动前先设 `ADMIN_PASSWORD=你的口令`。**不设口令时管理端仅限服务器本机访问**（公网打开 `/admin` 会提示 403），想远程管理就必须设口令
6. **用 pm2 守护**：`pm2 start server.js` + `pm2 save` + `pm2 startup`（实现崩溃自愈、开机自启、优雅重启；**不能只用 `npm start`**，那个一断终端网站就没了）
7. **Nginx 反代 + HTTPS**：把 80 / 443 转发到 Node 的 3000，配免费证书（certbot / acme.sh）。Nginx 与 Node 同机时反代识别开箱即用；**反代不在同一台机器**时记得加环境变量 `TRUST_PROXY=1`，否则阅读量防刷会把所有读者算成同一个 IP（偏严，但不会出错）
8. **防火墙**：只开 80、443

> **可选：套 Cloudflare（免费）**——把域名 DNS 托管到 Cloudflare 并开启「代理模式」，能隐藏真实服务器 IP（防扫描、防直接攻击）并白嫖免费 HTTPS 和基础加速。注意：这解决不了备案问题，微信内仍打不开未备案域名。套 Cloudflare 后同样需要 `TRUST_PROXY=1`。

### 路线 B：国内 + 备案

- 流程同上，但先做 **ICP 备案**（域名实名 + 服务器 + 身份证，审核 1~3 周）
- 备案通过后才能用 80 端口，才能被微信 / 百度正常访问
- 靠朋友圈传播、想被百度收录 → 走这条

### 上线前必做三件事

1. **管理口令**：`config.js` 里 `adminPassword` 或环境变量 `ADMIN_PASSWORD`，**必须设**（不设时公网无法进入管理端）
2. **定时备份**：写计划任务（crontab）每天把 `data/` 复制到**服务器之外**（本地电脑 / 网盘 / 对象存储）——服务器挂了数据还在
3. **内容合规**：只放你自己写的 / 已授权的 / 公版作品（作者去世 50 年以上）。公网运营实名可查，传有版权的书会被要求下架、赔偿，收费运营更可能被追刑责

### 本机 / 测试

- **本机**：`npm install && npm start`
- **免费低配主机**：支持 Node 即可（Render / Railway / Fly.io 免费档，注意 SQLite 建议挂持久卷；NAS / 旧电脑 + 内网穿透也可以试）
- **备份**：复制 `data/novels.db` 和 `data/uploads/` 即可；**迁移**：新服务器装好环境后，把整个项目（含 `data/`）放进去重新启动

## 注意事项

**上传相关**
1. **格式**：只支持纯文本 `.txt`（其他扩展名在上传入口直接拒绝），`.docx / .epub / .pdf` 不支持；一次最多传 **20 个文件**，单个文件 **≤ 200MB**
2. **编码**：正文自动识别 UTF-8 / GBK / GB18030 / Big5（先整本做 UTF-8 严格校验，非 UTF-8 再采样探测，不会把中文文件名或正文解乱；繁体无法保证，建议先转简体）。个别文件识别错乱时，用记事本另存为「UTF-8」再传即可
3. **书名 / 作者**：书名一律取 **TXT 文件名**（去掉 `.txt` 后缀）——文件名就是你设计好的小说名，**中文文件名按 UTF-8 处理、不会乱码**；作者自动识别「作者：xxx」的行。识别不对就在编辑页手动改
4. **章节切分**：自动识别「第X章 / 回 / 节 / 卷」「Chapter X」「序章 / 楔子 / 引子 / 前言 / 尾声 / 后记 / 终章 / 番外」。规则是启发式的（防止把正文切进标题），个别排版怪异的文件可能切错，用「编辑页 → **重新切分**」填自定义正则补救
5. **卷标题**：开头「第一卷」这类后面没有正文的标题行不会生成空章节；带卷简介的卷标题会正常保留为章节
6. **兜底**：整本没匹配到任何章节标题时，会整本作为「第 1 章」入库（不会丢内容）
7. **同名覆盖更新**：再次上传与已有**同名**的文件会覆盖章节并保留原 id、阅读量、收藏数——很适合给连载书籍更新内容。覆盖成功后会**自动删除旧的上传源文件**（新文件接管），`data/uploads/` 不会越积越多；解析失败的上传文件也会被清理
8. **封面**：不传封面会自动生成渐变 SVG；自定义封面支持 PNG / JPG / GIF / WebP / SVG，单张 ≤ 5MB。上传的 SVG 打开时禁止执行脚本（CSP 防护）

**自动排版**
9. **什么是硬折行**：很多 TXT 是「固定宽度硬折行」排版——每行在固定字数处断行，经常断在句子中间，前台会渲染成大量碎片化短段。编辑页「自动排版」先检测（dry-run，不动数据），展示前 3 个硬折行章节的重排前后对比，确认后整书重排；重排只把断行拼回段落、去掉行首尾空白，**不增删任何文字**
10. **哪些不会被重排**：正常排版、一句一行（诗词体）、大段连排（无换行符，无法可靠断段）的章节都会原样保留；单章编辑器里可用「重排本段」预览后手动保存

**数据与隐私**
11. **浏览器本地数据**：「最近在读」、我的收藏、书评昵称、阅读页主题字号等存在**浏览器 localStorage / cookie**——换浏览器、无痕模式、清除缓存都会丢；而后台的阅读量 / 收藏数 / 评分统计按匿名 cookie 存在服务端，不受影响
12. **计数规则**：阅读量同一 IP 30 秒进同一章只 +1；收藏、评分、评论按同一浏览器（cookie）去重，各算一次
13. **备份 = 复制 `data/novels.db` 和 `data/uploads/`**，恢复时原样放回即可；上传的源 TXT 也在 `data/uploads/` 里

**安全**
14. **管理口令**：默认**留空**。留空时管理端**仅限本机（127.0.0.1）访问**——本机使用不受任何影响，但公网访问 `/api/admin/*` 一律 403。公网部署想远程管理，必须设置 `ADMIN_PASSWORD`；设好后登录口令采用恒时比较，同 IP 每分钟最多错 5 次，会话 7 天过期
15. **错误信息脱敏**：服务器内部错误（5xx）只记日志，返回给前端的是通用文案，不泄露路径 / 表结构
16. `/admin` 是隐藏入口：设口令前它是「藏起来 + 锁在本机」，设口令后任何人都要凭口令进入

**版权与合规**
17. 只上传自己写的、已授权的或公版作品；本站为公益用途，侵权内容由上传者自行负责

**运维**
18. better-sqlite3 单连接够个人 / 小站使用；流量增大后可迁 PostgreSQL，字段结构兼容
19. 服务重启不影响数据；`Ctrl + C` / `pm2 stop` 会优雅关闭（处理完存量请求、WAL 落盘后再退出）；编辑书籍或章节后「最新更新」与「更新榜」会自动刷新

## 近期优化（v1.1）

- **修复**：列表页「连载中」筛选恒为空（下拉值与库中状态值不匹配）；首页 / 列表页分类导航因接口竞态永不渲染；编辑页封面加载失败回退失效；书籍被删后阅读页目录请求崩溃
- **安全**：未设口令时管理端仅限本机；登录恒时比较 + 失败限流 + 会话过期；`trust proxy` 收紧防伪造 IP 刷阅读量；5xx 错误信息脱敏；TXT 上传白名单；搜索词 LIKE 转义；上传 SVG 禁脚本
- **性能**：TXT 解析 / 排版重排移入 worker 线程（上传大文件不再卡住全站）；每章字数落库（`chapters.chars`，自动迁移）；新增 `GET /api/books?ids=` 批量接口消除收藏页 / 首页 N+1 请求；分类与搜索日志索引；自动封面与静态资源缓存；全站 gzip；删章后重排改单条 SQL
- **健壮性**：上传写库整体事务化（中途失败不再留下空书）；同名覆盖自动清理旧源文件；解析失败清理残留文件；优雅关闭（SIGTERM/SIGINT 落盘退出）；首页轮播后台标签页自动暂停
- **清理**：根目录约 110MB 测试 TXT 与调试脚本移入 `data/test-files/`（确认不需要可直接删除该目录）；移除死接口与死代码；`.gitignore` 补全
